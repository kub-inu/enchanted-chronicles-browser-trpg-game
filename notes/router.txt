ROUTER CONTROLLER SIGNATURE CHEATLIST

POVOLENÉ SIGNATÚRY (len tieto 4)

public function action(): void
public function action(Request $request): void
public function action(array $params): void
public function action(Request $request, array $params): void

KEDY POUŽIŤ KTORÚ

action()

Použi keď:

renderuješ page
nič nečítaš z requestu
nepotrebuješ URL params

Príklady:
public function home(): void
public function loginPage(): void
public function registerPage(): void

action(Request $request)

Použi keď:

čítaš input (POST, GET)
pracuješ s formulárom
používaš query, body, session, cookies

Príklady:
public function login(Request $request): void
public function register(Request $request): void
public function search(Request $request): void

action(array $params)

Použi keď:

potrebuješ hodnoty z URL
route obsahuje {param}

Príklady:
public function verify(array $params): void
public function showProfile(array $params): void

Použitie:
$params['id']
$params['token']

action(Request $request, array $params)

Použi keď:

potrebuješ request + URL parametre
napr. edit, update, kombinované operácie

Príklady:
public function update(Request $request, array $params): void
public function changePassword(Request $request, array $params): void

ZAKÁZANÉ (toto nepoužívaj)

public function action($params)
public function action($request)
public function action(Request $request, $params)
public function action(array $params = null)
public function action(?array $params)
public function action(Request $request, $params = null)
public function action($request, $params)

PRAVIDLÁ

nikdy nepoužívaj netyped parametre
nikdy nepoužívaj default hodnoty (= null)
nikdy nepridávaj argumenty, ktoré nepoužívaš
params sú vždy: array $params
request je vždy: Request $request
poradie musí byť:
Request vždy prvý, params vždy druhý

RÝCHLE ROZHODOVANIE

nič nepotrebujem → ()
potrebujem input → (Request)
potrebujem URL → (array)
potrebujem oboje → (Request, array)
